# Запуск Diesel локально

## 1. Что нужно один раз

- **Docker Desktop** установлен и запущен (значок кита в строке меню).
- **Telegram-бот.** В Telegram откройте @BotFather:
  - новый бот: `/newbot` → придумайте имя и username (например `DieselUzBot`) → BotFather пришлёт токен;
  - или старый бот: `/mybots` → бот → *API Token* → *Revoke current token* (старый токен был в публичном репозитории, его нужно заменить).
- **Ключ Claude (необязательно).** https://console.anthropic.com → *API Keys* → *Create Key*. Без него повреждения оцениваются только локально (пока локальная модель не обучена — грубой эвристикой).

## 2. Файл `.env`

В корне проекта есть файл `.env` (в git не попадает). Впишите:

```
TELEGRAM_BOT_TOKEN=токен_от_BotFather
TELEGRAM_BOT_NAME=username_бота_без_@
ANTHROPIC_API_KEY=ключ_claude_или_пусто
```

Никому не пересылайте эти значения и не вставляйте их в чаты.

## 3. Запуск

```bash
docker compose up -d --build
```

Первая сборка долгая (10–30 минут: скачиваются PyTorch и модели распознавания). Потом — секунды.

| Что | Адрес |
|-----|-------|
| Админка | http://localhost:4173/ |
| Кабинет водителя | http://localhost:4173/driver.html |
| API | http://localhost:8080 |
| AI-сервис (статус) | http://localhost:8000/ |
| MySQL | `localhost:3307`, БД `fleetscan`, пользователь `taxiuser` / `taxi123` (только для локальной разработки) |

## 4. Первый вход

1. Напишите боту `/start` → введите название автопарка → вы администратор.
2. Отправьте боту `/web` → придёт код вида `K7P2-QX9M` (живёт 5 минут).
3. Откройте http://localhost:4173/ → введите код → вы в админке.
4. Добавить водителя: в боте `/add_driver` → бот даст ссылку-приглашение для водителя.
5. Водитель: открывает ссылку → `/register_car` → присылает фото машины.

Паролей у сайта нет: вход только через одноразовый код из бота.

## 5. Полезные команды

```bash
docker compose ps                 # что запущено
docker compose logs -f app        # логи бэкенда и бота
docker compose logs -f ai         # логи распознавания
docker compose restart app        # перезапуск после смены .env
docker compose down               # остановить (данные сохраняются)
docker compose down -v            # остановить и УДАЛИТЬ все данные (БД, фото)
```

## 6. Если что-то не так

- `Set TELEGRAM_BOT_TOKEN in .env` — не заполнен токен в `.env`.
- Бот молчит — проверьте `docker compose logs app | grep -i bot`; токен мог быть отозван, или этот же бот запущен где-то ещё (Telegram допускает только одно подключение).
- Порт занят — остановите программу на портах 3307/8080/8000/4173 или поменяйте порты в `docker-compose.yml`.
